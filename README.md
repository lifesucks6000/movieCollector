# Movie List Manager
A lightweight, responsive web application for managing your personal movie collection. Built with vanilla web technologies and a Node.js backend, this project showcases fundamental full-stack development skills.
## Features:

 - Movie List Display: View your curated list of movies at a glance.
 - Add New Movies: Easily expand your collection with a simple input form.
 - Edit Entries: Update movie titles or correct any mistakes.
 - Delete Movies: Remove entries you no longer want in your list.
 - Responsive Design: Enjoy a seamless experience on both desktop and mobile devices.

## Tech Stack:
### Frontend:

 - HTML5 for structure
 - CSS3 for styling and responsiveness
 - Vanilla JavaScript for dynamic interactions

### Backend:

 - Node.js runtime environment
 - Express.js framework for routing and middleware

## Key Learning Points:

 - RESTful API design and implementation
 - CRUD operations in a full-stack environment
 - Asynchronous JavaScript for smooth user experience
 - Responsive web design principles
 - Server-side rendering with Express

This project serves as an excellent foundation for understanding how frontend and backend technologies interact in a web application. It's perfect for beginners looking to grasp full-stack concepts or for those wanting to demonstrate proficiency in vanilla web technologies.
